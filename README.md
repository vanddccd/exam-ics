# 考试日历订阅源

本仓库只存放 .ics 日历文件，供日历客户端订阅。

## 订阅方式（iPhone）

1. 复制下面的链接
2. **在 Safari 或「备忘录」里打开**（微信内置浏览器打不开）
3. 系统弹出「订阅日历」→ 选颜色 → 完成
